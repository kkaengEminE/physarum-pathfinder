## 소개

**점균류(Physarum polycephalum)** 는 뇌도 신경계도 없는 단세포 생물이지만, 먹이원 사이의 최적 네트워크를 스스로 형성하는 놀라운 능력을 가지고 있습니다.

2010년 도쿄대 연구진은 점균류가 도쿄 수도권 철도망과 거의 동일한 네트워크를 만들어낸다는 것을 발견했습니다. 이 시뮬레이션에서 당신은 직접 먹이를 배치하고, 점균류가 최적 경로를 찾아가는 과정을 관찰할 수 있습니다.

## 실험 도구

| 도구 | 설명 |
|------|------|
| 🟡 먹이 (오트밀) | 먹이원을 배치합니다. 점균류가 이곳을 향해 뻗어갑니다 |
| 🟢 점균류 씨앗 | 점균류 시작점을 놓습니다. 200개 입자가 산포됩니다 |
| 🧱 벽 (장애물) | 통과 불가 지형을 설치합니다 |
| 🔦 빛 (혐광) | 점균류를 밀어내고 경로를 약화시킵니다 |
| 💧 습기 | 해당 영역의 점균류 성장을 촉진합니다 |
| 🗑️ 먹이 제거 | 먹이원을 제거하면 해당 경로가 서서히 퇴화합니다 |

## 배경 지도 기능

서울, 도쿄 등의 지도 이미지를 업로드하면 캔버스 배경에 반투명으로 깔립니다. 지도 위에 도시 위치에 먹이를 놓고, 점균류가 실제 교통망과 비슷한 네트워크를 만드는지 관찰해보세요.

## 플레이 방법

1. **실험 시작하기**를 클릭합니다.
2. (선택) **🗺️ 지도 올리기**로 배경 이미지를 설정합니다.
3. **🟡 먹이**를 여러 곳에 배치합니다.
4. **🟢 점균류 씨앗**을 먹이 근처에 놓습니다.
5. 점균류가 사방으로 탐색하며 먹이 사이에 **최적 네트워크**를 형성하는 과정을 관찰합니다.
6. **🔦 빛**이나 **🗑️ 먹이 제거**로 네트워크가 재구성되는 과정을 실험합니다.

## 핵심 알고리즘

- **에이전트 기반 Physarum 모델**: 각 입자가 3방향 센서로 화학물질 농도를 감지하여 이동
- **양의 피드백**: 많이 지나간 경로는 흔적이 강화되어 더 많은 입자를 끌어들임
- **자연 퇴화**: 사용되지 않는 경로는 증발로 서서히 사라짐
- **확산**: 인접 셀로 화학물질이 번져 경로가 자연스럽게 굵어짐

## 기술 스택

- **TypeScript** (Strict Mode) — 외부 라이브러리 없는 순수 구현
- **HTML5 Canvas 2D** — 최대 5000개 입자 + 화학 흔적 격자 실시간 렌더링
- **Vite** — 빌드 및 개발 서버
